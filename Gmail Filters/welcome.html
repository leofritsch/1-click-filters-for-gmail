🔧 How It Works

1

Select Emails in Gmail

In your Gmail inbox, select one or more emails by clicking the checkboxes next to them. You can select emails from different senders to filter them together.

2

Look for the Filter Button

When emails are selected, a filter button will appear in Gmail's toolbar. Click this button to start the automated process.

3

Watch the Automation

The extension automatically opens Gmail's filter creation dialog, fills in all the sender email addresses, and applies smart default settings.

4

Just Choose a Label

The extension pre-configures everything to skip your inbox and never go to spam. You only need to pick or create a label to organize these emails!

🔄 Important: Refresh After Each Filter

After you create a filter, if you want to create another one you'll need to refresh your Gmail page before the icon shows up again.
